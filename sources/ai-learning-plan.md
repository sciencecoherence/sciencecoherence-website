# 6-Month Plan: True Beginner → AI Software Engineer (Generalist)

**Start date:** June 22, 2026
**Hire target:** December 22, 2026
**Time budget:** 22 hrs/week (~575 hrs total)
**Cert anchor:** IBM AI Developer Professional Certificate (Coursera)
**Job target:** Junior AI software engineer — builds production AI features (LLMs, APIs, agents) into real apps

---

## The hire-ready picture (what Month 6 actually looks like)

Recruiters and hiring managers for junior AI software engineer roles in late 2026 will look for, in this order:

1. **A public GitHub with 3–4 deployed projects** that show you can ship end-to-end — not notebooks, *live apps with a URL*.
2. **Demonstrable LLM/RAG/agent fluency** — at least one project that uses an LLM API, vector store, and shows prompt engineering judgment.
3. **Solid Python + one web framework** (FastAPI is the default for AI services).
4. **The IBM cert** as a credibility signal (necessary, not sufficient).
5. **A clean resume + LinkedIn + 1-page portfolio site** with project demos.
6. **20–40 thoughtful applications and 5–10 interview cycles** completed by week 26.

Everything below is engineered to deliver that picture.

## Month 1 — Foundations (Jun 22 – Jul 22)

**Theme:** "Stop being a beginner."

**Weekly cadence (22 hrs):**
- 12 hrs: Python fundamentals (CS50P or "Python for Everybody" via Coursera, runs in parallel with cert)
- 6 hrs: IBM cert Course 1 (Intro to Software Engineering) + Course 2 (Intro to AI)
- 3 hrs: Tooling — Git, GitHub, VS Code, command line, virtual environments
- 1 hr: Read & journal — `r/learnprogramming`, AI hiring posts on LinkedIn

**Concrete outputs by end of M1:**
- 30+ daily commits visible on GitHub profile
- 5 small Python projects in public repos (CLI tools, file processors, simple APIs)
- A polished GitHub `README.md` on your profile
- Linux/macOS terminal fluency (no GUI dependency)

**Reality check:** True beginners often plateau at week 3. If you're not writing Python without copy-paste by end of M1, slow down and repeat — don't push into AI content yet.

## Three things that will actually decide whether this works

1. **Ship publicly from Month 2.** A learning-log repo with weekly markdown notes is worth more than a perfect notebook nobody sees. Recruiters scan GitHub activity charts.
2. **Don't chase every new tool.** Master a small stack — Python, FastAPI, one LLM provider, one vector store, one frontend (Streamlit or Next.js). Depth beats breadth at junior level.
3. **Start applying in Month 4, not Month 6.** Early applications are practice. The first 20 applications teach you what the next 20 should look like.

---

## Risks to plan around

| Risk | Mitigation |
|---|---|
| You hit a Python wall in Month 1 | Slow down M2; cert can compress later. Foundations are non-negotiable. |
| The market tightens for juniors | Pair AI/ML with adjacent dev skills (TypeScript, basic frontend); apply to mid-size companies, not just FAANG. |
| Burnout at week 14–16 | Schedule a 1-week deload between M3 and M4. Maintain sleep and primal nutrition (your existing protocol matters here). |
| Imposter syndrome before applying | Send first 5 apps in Month 4. Rejection becomes neutral information after the first 10. |
| Cert without portfolio | The portfolio is the cert. Treat the IBM credential as the floor, not the work. |
